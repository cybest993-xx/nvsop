Web 视觉参考

这是设计语言的实物，不是规格书。页面直接读取 apps/control-web/src/styles/tokens.css，所以它不会与产品漂移——改了 token 再打开这一页，看到的就是新的。规则与理由见 frontend.md。

调色板

每个 token 只有一个用途。状态色只出现在状态上——库存计数不是状态，所以计数不着绿色。

--color-primary 主色：主按钮、工具栏、当前导航项
--color-success 状态：已验证、可达、启用
--color-warning 状态：未验证、需人工确认
--color-danger 状态：连接失败、不可达
--color-sidebar-bg 侧栏底色
--color-panel-header 面板标题条
--color-table-header 表头行
--color-page-bg 内容区底色
--color-surface 卡片与面板
--color-text 正文
--color-text-muted 次要文字（白底约 5.1:1）
--color-border 分隔线与描边

字号阶

五档，组件从中挑一档，不自己造尺寸。中文行高比西文松：字形填满 em 框，西文上下留白。

--font-size-title
--line-height-title 工位与设备
--font-size-panel
--line-height-panel 连接器
--font-size-body
--line-height-body 已登记的工位、推理机、相机、点位与连接器。未验证的配置如实标为未验证，不推断在线或健康状态。
--font-size-secondary
--line-height-secondary 仅显示当前权限范围内的连接器
--font-size-label
--line-height-label 连接验证 · 可达性观测

--line-height-metric 1 284.5 s

状态

状态同时用文字与颜色表达，颜色从不单独承担意义。

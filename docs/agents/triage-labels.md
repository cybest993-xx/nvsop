# Triage labels

Installed skills use the following role-to-label mapping.
[Issue rules](../engineering/issues.md#task-types-and-labels) owns
the meanings and readiness requirements.

| Canonical role | Tracker label |
|---|---|
| `needs-triage` | `needs-triage` |
| `needs-info` | `needs-info` |
| `ready-for-agent` | `ready-for-agent` |
| `ready-for-human` | `ready-for-human` |
| `wontfix` | `wontfix` |

Use the tracker label when a skill names a canonical role.

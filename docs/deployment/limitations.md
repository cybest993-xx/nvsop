# 已知限制与验证边界

本文区分“代码/设计已经明确的限制”和“仍需目标环境证明的能力”。后者不能因为源码存在、公开规格看起来足够或相邻型号可用就转写成产品承诺。完整现场门禁见 [`../research/target-environment-validation-matrix.md`](../research/target-environment-validation-matrix.md)。

## 已确认的产品限制

### 仅动作编号作为开始信号时，作业遍数是下界

如果工位只用动作编号作为开始信号，操作员漏做**起始动作**时 SOP 实例不会开启，因此该遍作业不会被记录，而不是被记录为“不通过”。这是 [ADR-0009](../adr/0009-single-channel-perception-limit.md) 的明确取舍。

对产量对账或“不能漏一遍”敏感的工位，应配置外部物理开始信号（例如工件到位）或独立计数信号。销售、交付和界面必须显式表达这个边界。

### 当前首个生产连接器类型只有 Hikvision ISAPI

边缘配置解析器当前接受的 production connector type 为 `hikvision_isapi`。这不表示所有海康型号、固件、区域版本都具备相同 I/O、推送、认证或编码能力；具体能力仍必须实测。

### 训练素材只接受单个视频文件

当前控制面只允许逐个上传视频并通过预签名 URL 直传 MinIO；不接受压缩包，后端不解压。标注动作时间段使用复用的 NVIDIA React 标注 UI。

### Web 首切片目标有限

当前 Web 基线是简体中文、桌面 Chrome/Edge 当前稳定版，目标分辨率 1366×768～1920×1080。原生移动端、企业身份源以及路线中明确后置的实时大屏/统计等能力不能从首切片存在性推导为已交付。

### `/api/v1` 不是并行版本轴

系统不会通过长期并行 `/api/v2` 来吸收破坏性变化。兼容演进和协同升级规则见 [ADR-0003](../adr/0003-api-v1-is-a-fixed-prefix.md) 与 [`upgrade.md`](upgrade.md)。

## 中心离线时的边界

设计目标是推理机自治：取流、感知、判定、违规锁存、本地证据缓冲与不依赖中心的处置继续；配置变更、中心看板、复核和上报会暂停，恢复后对账。

物理输出写入还受执行权/租约约束；不能把“中心离线仍能判定”误读为“任何中心故障下都无限期允许物理写入”。具体设计见 [`../design/mechanisms/edge-autonomy.md`](../design/mechanisms/edge-autonomy.md)。目标环境仍必须证明断网、重启和恢复行为。

## 仍待目标环境验证的能力

下列内容在对应门禁完成前只能写成目标或候选基线：

| 能力 | 为什么代码/规格不够 |
|---|---|
| RTX 4090 实时路数/多后端容量 | 显存规格、`num_gpus: 1` 和配置上限不等于真实 DDM+VLM 并发容量 |
| RTX 4090 7×24 生产适用性 | gaming GPU 可作开发/受控试点候选；生产长稳、散热、功耗和恢复必须实测 |
| 指定海康型号的 RTSP/ISAPI/I/O 能力 | 型号后缀、固件、区域版本和通道会改变能力；不能从其他型号外推 |
| 掉流/重连/主机重启恢复 | 必须在真实流与故障注入下证明时间锚、不可观察区间和恢复语义 |
| 多路预览与零转码 | B 帧、codec/profile、浏览器硬解和客户端资源都需真设备/真浏览器验证 |
| 物理 I/O 时延与可靠性 | 推送/轮询、最大投递延迟、保序和丢边沿必须实测；摄像机继电器不应被宣称为安全联锁 |
| 真离线安装/启动/回滚 | 必须在拒绝公网的干净主机证明无运行时下载或隐式外连 |
| 模型/SDK/镜像商业再分发 | 需要逐制品许可证与责任边界闭包，工程文档不能替代许可裁决 |
| 72 小时/7 天稳定性 | 短时 smoke 或单元/集成测试不能证明资源泄漏、热设计和长期队列稳定性 |

基座自带的性能客户端并不能提供真实并发证明，因此容量数据必须由 NVSOP 的目标环境测试工具产生。

## 不应被“绿色 CI”替代的证据

`make check`、`make check-integration`、浏览器 E2E 和固定开发实例可以证明软件契约，但不能关闭 GPU、真相机、网络退化、现场 I/O、离线包、许可证、长稳和多机容量门禁。没有真实部署变量时被 skip 的专项测试也不是绿色发布证据。

交付结论必须携带环境身份、镜像/model digest、输入数据、命令/报告与明确的通过预算；否则结果不可复现。
